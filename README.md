# 音乐计算器

一个基于H5技术的移动端音乐计算器应用，将传统计算器界面与音乐功能完美结合。

## 功能特性

- 🎵 **音符映射**: 数字1-6对应中央C的do re mi fa sol la，7-9对应高八度do re mi
- 🎹 **音调调节**: 加号按钮升调，减号按钮降调
- 🔊 **实时播放**: 按下按钮即时播放对应音符
- ⏱️ **长按持续**: 支持长按按钮持续发声
- 🎶 **和弦播放**: 支持同时按下多个按键发出和声
- 🔄 **滑动切换**: 按下后滑动到其他按钮自动切换音符
- 📱 **移动优化**: 专为移动端设计的触摸界面
- 🎨 **现代设计**: 玻璃拟态设计风格，美观大方

## 使用说明

### 基本操作
- **数字键1-6**: 播放中央C音阶 (Do, Re, Mi, Fa, Sol, La)
- **数字键7-9**: 播放高八度音阶 (Do↑, Re↑, Mi↑)
- **+ 按钮**: 升调（提高半音）
- **- 按钮**: 降调（降低半音）
- **C 按钮**: 清除音调设置，恢复到默认C4音调

### 交互方式
- **点击播放**: 短按按钮播放音符
- **长按持续**: 长按按钮可让音符持续发声
- **和弦播放**: 同时按下多个按钮播放和声
- **滑动切换**: 按下按钮后滑动到其他按钮自动切换音符
- **音量调节**: 使用底部滑块调节音量大小

## 技术实现

### 核心技术
- **Web Audio API**: 用于音频生成和处理
- **HTML5/CSS3**: 响应式界面设计
- **JavaScript ES6+**: 交互逻辑和音频控制

### 音频特性
- 使用正弦波振荡器，音色纯净
- 支持音频淡入淡出效果
- 自动处理移动端音频上下文
